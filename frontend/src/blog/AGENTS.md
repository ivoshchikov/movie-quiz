# Blog editorial work

For every new article, selection or substantive rewrite, read `docs/blog/AUTHORIAL_STYLE.md` from the repository root and apply it to the selection as well as the prose. The owner has made the original editorial approach the first priority.

- Write public content in English using the Hard Quiz house voice. Each article needs a specific editorial question and justified selections or examples.
- Add supported observations, useful comparisons and honest reservations. Avoid a repeated paragraph template across every title.
- Never invent a human author, personal screening, interview, playback test or other first-hand experience. Separate facts, attributed criticism and original interpretation.
- Keep the spoiler boundary, linked evidence and image provenance. Use the existing external-link component for external destinations.
- Keep publication, substantive modification and factual verification dates separate. A voice edit does not renew availability checks.
- Preserve stable article URLs and verify generated metadata, RSS, sitemap and rendered HTML using the relevant existing checks.

Other applicable project and user instructions remain in force.
